THE SCHEDULING ENGINE

How TimelyAI Works

Modern colleges have hundreds of interrelated scheduling constraints. TimelyAI uses Google OR-Tools CP-SAT (Constraint Programming) to solve the exact formulation mathematically without heuristics or trial-and-error.

1

Structure Input Data

Enter your classes, course subjects, weekly periods, faculty names, and institutional timings into the standardized Excel template.

2

Rigorous Feasibility Check

Before launching the solver, the system checks capacity: ensuring teacher loads don't exceed weekly limits and room/period slots are mathematically sufficient.

3

Constraint Optimization

CP-SAT enforces hard rules (no faculty or class clashes) while optimizing soft objectives: balanced daily study loads and compact consecutive lectures.

4

Interactive Edit & Export

Review the schedule in the browser, adjust individual sessions with real-time conflict detection, and download formatted Excel sheets or print-ready PDFs.

CAPABILITIES

Supported Academic Features

Designed specifically for higher education institutions, engineering colleges, polytechnics, and schools.

🚫

Zero Double-Bookings

No faculty member or student class will ever be scheduled in two places simultaneously. Clash prevention is enforced at the constraint level.

🔬

Multi-Period Continuous Labs

Specify 2-period practicals or 3-period workshops. TimelyAI schedules them continuously within the same day without lunch break interruptions.

🔗

Shared Branch Lectures

Merge multiple branches (e.g. CSE Section A and ECE Section A taking Common Mathematics) into one joint period under a single faculty member.

⚖️

Balanced Weekly Load

Spreads subject lectures evenly across working days so students don't face three lectures of the same subject on the same day.

✏️

Interactive Manual Fine-Tuning

Click any session in edit mode to change time, room, or faculty. Immediate warning badges alert you if a proposed shift causes a conflict.

⚡

Serverless Cloud Execution

Engineered for high performance with in-memory streaming, sub-10s solving limit, and zero local filesystem dependencies for cloud deployment.

DOCUMENTATION

Excel Input Structure Guide

To ensure smooth validation and schedule generation, your workbook must contain the following sheets:

Sheet 1

Classes

Defines every academic cohort in your institution.

Column Type Description & Example
course_name Text Academic degree or program (e.g. B.Tech, BCA)
branch_name Text Specialization or department (e.g. CSE, Mechanical)
semester Number/Text Semester or term identifier (e.g. 4, 6)
section Text Section letter or division (e.g. A, B)
Sheet 2

Subjects

Maps subjects to classes with required period counts.

Column Type Description & Example
class_id Text Compound class ID, e.g. B.Tech_CSE_Sem4_A
subject_name Text Course name (e.g. Operating Systems, DBMS Lab)
weekly_periods Number Total periods per week required (e.g. 4)
periods_per_session Number Continuous slot length: 1 for lecture, 2 for lab
subject_type Text Theory or Lab
Sheet 3

Teachers

Faculty roster and their subject qualification mapping.

Column Type Description & Example
teacher_name Text Full name or title (e.g. Dr. Sharma, Prof. Patel)
subjects Text Comma-separated list of subjects this teacher can teach
Sheet 4

Settings

Key-value configurations for working hours, days, and breaks.

Setting Key Example Value Description
working_days Monday, Tuesday, Wednesday, Thursday, Friday Comma-separated list of active academic days
periods_per_day 7 Number of teaching periods per day
period_start_time 09:00 Institution opening time (HH:MM)
period_duration 50 Duration of each period in minutes
lunch_break_after 2 Period number after which lunch break occurs
lunch_duration 50 Lunch break duration in minutes
